# flow

Open-source engineering simulation in the browser — FEA, thermal, CFD solvers with AI-assisted mesh generation.

## What it does

Runs finite element analysis, heat transfer, and computational fluid dynamics simulations client-side. AI mesh generation suggests optimal mesh density based on geometry. No install — open the URL, upload a model, simulate.

## Stack

Python backend (FastAPI, NumPy, SciPy), React frontend (Three.js for 3D visualization), WebAssembly for client-side computation.
